# EXPENSE-TRACKER

- Backend
  - Spring Boot
  - Spring Security
  - Spring Data Jpa
  - JWT (for authentication)
  - Open API
  - Docker (for database)
- Frontend
  - TypeScript
  - React
  - React Router
  - Axios
  - Tailwind CSS
- Database
  - Postgres
